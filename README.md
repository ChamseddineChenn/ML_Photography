# ML Photography

A cinematic photography portfolio and digital storefront built for photographer Malek Larif. The experience brings together a visual landing page, image galleries, print offerings, and editorial content in one responsive website.

## Overview

ML Photography is designed to give the photographer's work the central role. The interface combines a strong visual presentation with clear paths to explore photographs, discover available prints, and read journal content.

### Highlights

- Cinematic, image-led landing page
- Photography gallery
- Prints shop experience
- Journal / editorial section
- Responsive web experience

## Technology

- **Next.js 16**
- **React 19**
- **TypeScript**
- **ESLint**

## Getting started

### Requirements

- Node.js (use a current LTS release)
- npm

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the local development server |
| `npm run build` | Create a production build |
| `npm start` | Run the production server |
| `npm run lint` | Run ESLint |

## Production

The application can be deployed to a platform that supports Next.js. The project is configured for a standard Next.js production build:

```bash
npm run build
npm start
```

Set the public site URL in the deployment environment as `NEXT_PUBLIC_SITE_URL` where required by the application.

## Project structure

The repository contains the Next.js application, shared UI and page code, and site content. Photographer-specific content and contact details are maintained in the project source.

## Notes

This repository presents the implementation and technology behind the website. Photography, branding, and client content belong to the photographer.
